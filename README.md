## Завдання
Створити клас із виконавчим методом, в якому створити масив з
об’єктів класу визначеному варіантом (п. 2). Відсортувати масив, за
одним з полів за зростанням, а за іншим — за спаданням<sup>2</sup>,
використовуючи при цьому стандартні засоби сортування (). Після
цього знайти в масиві об’єкт, який ідентичний заданому. Всі змінні
повинні бути описані та значення їх задані у виконавчому методі.
